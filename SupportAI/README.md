# SupportAI

Платформа поддержки клиентов: дашборд с аналитикой, обращения со статусами и приоритетами, окно ответов с подсказками из базы знаний, сама база знаний, тарифы и настройки. Данные хранятся в базе SQLite и сохраняются после перезапуска.

**Сейчас готов первый этап — основа проекта.** AI-генерация ответов, MCP и приём оплаты добавим отдельными этапами. Места, куда они подключаются, подготовлены (см. раздел «Следующие этапы»).

**Стек:** React + Vite + TypeScript, Tailwind CSS, Lucide Icons, Recharts, Python + FastAPI, SQLite.

---

## Что внутри

| Страница | Что умеет |
|---|---|
| **Дашборд** | Показатели (всего, активные, решённые, оценка клиентов), график «поступило / решено» за 7, 14 или 30 дней, переключение «график / таблица», диаграммы по статусам, приоритетам и каналам, последние обращения |
| **Обращения** | Таблица с вкладками по статусам, фильтром по приоритету, поиском и сортировкой; постраничный список; карточка обращения с перепиской; смена статуса, приоритета и исполнителя; ответ клиенту; создание и удаление обращений |
| **AI-помощник** | Очередь активных обращений и чат. Для каждого обращения подбираются статьи из базы знаний, ответ вставляется одной кнопкой. Кнопка «Черновик от AI» пока отключена и помечена «Скоро» |
| **База знаний** | Вопросы и ответы с поиском и фильтром по категориям; добавление, редактирование и удаление статей |
| **Тарифы** | Три плана, переключатель «помесячно / за год», индикатор использования. Тариф переключается сразу и без списаний, оплату добавим позже |
| **Настройки** | Данные компании, рабочие часы, подпись для ответов, уведомления, кнопка «Вернуть демонстрационные данные» |

## Что нужно установить (один раз)

1. **Python 3.10 или новее** — https://www.python.org/downloads/
   При установке обязательно поставьте галочку **«Add python.exe to PATH»**.
2. **Node.js 20.19 или новее** (лучше версия LTS) — https://nodejs.org

Больше ничего не нужно. Интернет нужен при первом запуске, чтобы скачать библиотеки.

---

## Запуск

1. Распакуйте архив в любую папку (лучше путь без русских букв, например `C:\Projects\SupportAI`).
2. Дважды щёлкните **`start.bat`**.
3. Подождите. При первом запуске скрипт сам установит библиотеки — это займёт несколько минут. Потом откроются два чёрных окна (**SupportAI Backend** и **SupportAI Frontend**) и браузер.
4. Готово: сайт на **http://localhost:5173**.

Следующие запуски занимают несколько секунд.
Чтобы остановить проект, закройте оба чёрных окна.

| Адрес | Что это |
|---|---|
| http://localhost:5173 | Сайт |
| http://127.0.0.1:8000/docs | Интерактивная документация API (можно пробовать запросы прямо в браузере) |
| http://127.0.0.1:8000/api/health | Проверка, что backend работает |

> Если в чёрном окне вместо русских букв появились странные символы, это не ошибка: на работу проекта это не влияет.

├── scripts/check-node.cjs     проверка версии Node.js для start.bat
│
├── backend/                   СЕРВЕР (Python + FastAPI)
│   ├── data/supportai.db      база данных SQLite (создаётся при первом запуске)
│   └── app/
│       ├── main.py            точка входа: подключает роутеры, обрабатывает ошибки
│       ├── config.py          настройки (читает .env)
│       ├── db.py              подключение к SQLite и описание таблиц
│       ├── schemas.py         проверка входящих данных и формат ответов
│       ├── errors.py          понятные ошибки на русском
│       ├── search.py          простой поиск по тексту (с учётом окончаний слов)
│       ├── seed.py            демонстрационные данные
│       ├── routers/           АДРЕСА API (что вызывает сайт)
│       │   ├── tickets.py       обращения и клиенты
│       │   ├── knowledge.py     база знаний
│       │   └── system.py        статистика, настройки, тарифы
│       └── services/          ЛОГИКА и запросы к базе
│           ├── tickets.py  knowledge.py  stats.py
│           └── settings.py  plans.py
│
└── frontend/                  САЙТ (React + Vite + TypeScript)
    ├── index.html
    ├── package.json           список библиотек сайта
    ├── vite.config.ts         настройки сборки; здесь же прокси /api → backend
    └── src/
        ├── main.tsx           точка входа
        ├── App.tsx            список страниц (маршруты)
        ├── index.css          ДИЗАЙН-СИСТЕМА: цвета, шрифты, скругления, анимации
        ├── pages/             страницы: Dashboard, Tickets, Assistant, Knowledge, Plans, Settings
        ├── components/
        │   ├── layout/        боковая панель, верхняя строка, каркас страницы
        │   ├── ui/            кнопки, поля, бейджи, окна: общие «кирпичики»
        │   ├── charts.tsx     мини-график, подсказка графиков, индикатор динамики
        │   ├── TicketDrawer.tsx    выезжающая карточка обращения
        │   └── NewTicketModal.tsx  окно «Новое обращение»

**Как связаны части.** Страница (`pages/`) вызывает функцию из `api/client.ts` → запрос уходит на адрес из `backend/app/routers/` → роутер вызывает функцию из `services/` → та читает или пишет в SQLite. Данные проверяются в `schemas.py`.

## Данные и SQLite

- База лежит в файле `backend/data/supportai.db`. Всё, что вы создаёте или меняете на сайте, пишется туда и остаётся после перезапуска.
- При самом первом запуске база заполняется демонстрационными данными: 16 клиентов, 64 обращения с перепиской и 17 статей базы знаний. Даты считаются от текущего дня, поэтому графики всегда выглядят «живыми».
- **Вернуть демо-данные:** на сайте «Настройки» → «Вернуть демонстрационные данные». Либо остановите проект, удалите файл `supportai.db` и запустите снова.
- **Сделать резервную копию:** остановите проект и скопируйте файл `supportai.db`.
- Посмотреть таблицы можно бесплатной программой DB Browser for SQLite (https://sqlitebrowser.org).

## API

Полный список с возможностью пробовать запросы: http://127.0.0.1:8000/docs

| Метод | Адрес | Действие |
|---|---|---|
| GET | `/api/tickets` | Список обращений. Параметры: `status`, `priority`, `q` (поиск), `sort`, `page`, `page_size` |
| POST | `/api/tickets` | Создать обращение (клиент создаётся автоматически, если такого email ещё нет) |
| GET | `/api/tickets/{id}` | Обращение с перепиской |
| PATCH | `/api/tickets/{id}` | Изменить статус, приоритет, тему, канал, категорию, исполнителя |
| DELETE | `/api/tickets/{id}` | Удалить обращение |
| POST | `/api/tickets/{id}/messages` | Добавить сообщение в переписку |
| GET | `/api/customers` | Список клиентов, поиск по параметру `q` |
| GET | `/api/knowledge` | Статьи; параметры `q` (поиск) и `category` |
| POST | `/api/knowledge` | Создать статью |
| GET / PATCH / DELETE | `/api/knowledge/{id}` | Прочитать, изменить, удалить статью |
| GET | `/api/knowledge/categories` | Категории со счётчиками |
| GET | `/api/knowledge/suggest?text=…` | Подходящие статьи для текста обращения (поиск по словам, без AI) |
| GET | `/api/stats/overview` | Статистика дашборда |
| GET / PATCH | `/api/settings` | Прочитать и сохранить настройки |
| POST | `/api/settings/reset-demo` | Вернуть демонстрационные данные |
| GET | `/api/plans` | Тарифы и текущий план |
| POST | `/api/plans/select` | Выбрать тариф |

**Ошибки.** Если данные неверные (пустая тема, плохой email, неизвестный статус), backend отвечает понятным сообщением на русском, а сайт показывает его в уведомлении. Если обращения не существует, ответ «Обращение не найдено» (код 404).

## Как менять проект

| Что хочется | Куда смотреть |
|---|---|
| Поменять фирменные цвета (синий, фиолетовый) | `frontend/src/index.css`, блок `@theme`: значения `--color-cobalt-*` и `--color-violet-*` |
| Поменять шрифты | Ссылка в `frontend/index.html` и `--font-sans` / `--font-display` в `index.css` |
| Поменять названия статусов и приоритетов | `frontend/src/lib/constants.ts` |
| Поменять название и цену тарифов, их возможности | `backend/app/services/plans.py`, список `PLANS` |
| Поменять демо-клиентов, темы обращений и статьи | `backend/app/seed.py`, затем «Вернуть демонстрационные данные» |
| Поменять пункты боковой панели | `frontend/src/components/layout/Sidebar.tsx` |
| Добавить новую страницу | Файл в `frontend/src/pages/`, затем `<Route>` в `App.tsx` и пункт в `Sidebar.tsx` |
| Добавить поле в обращение | `db.py` (таблица), `schemas.py` (схемы), `services/tickets.py` (запросы), `api/types.ts` (тип на сайте) |
| Добавить новый адрес API | Функция в `services/`, адрес в `routers/`, вызов в `frontend/src/api/client.ts` |

Если меняете таблицы в `db.py`, удалите `backend/data/supportai.db`, иначе старая база останется без новых полей.

## Запуск вручную (без start.bat)

Откройте PowerShell в папке проекта.

**Один раз:**
```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
cd frontend
npm install
cd ..
```

**Backend** (первое окно):
```powershell
.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload --reload-dir backend --port 8000
```

**Frontend** (второе окно):
```powershell
cd frontend
npm run dev
```

Откройте http://localhost:5173.

### Режим показа: один адрес

Для защиты диплома удобно запустить всё одним окном. Соберите сайт один раз:
```powershell
cd frontend
npm run build
```
Затем запустите только backend (команда выше) и откройте **http://127.0.0.1:8000**. Backend сам отдаст собранный сайт. После правок в `frontend/src` соберите сайт заново.

Проверка типов TypeScript (необязательно): `npm run typecheck` в папке `frontend`.

## Частые проблемы

| Проблема | Решение |
|---|---|
| «Python не найден» | Переустановите Python и поставьте галочку «Add python.exe to PATH» |
| «Node.js не найден» или версия слишком старая | Установите Node.js LTS с https://nodejs.org |
| На сайте красная плашка «Не удаётся связаться с сервером» | Backend не запущен. Посмотрите окно «SupportAI Backend»: там написана причина |
| «Address already in use» / порт занят | Закройте старые окна проекта. Другая программа может занимать порт 8000 или 5173 |
| Установка библиотек зависла или упала | Проверьте интернет. Удалите `.venv` (или `frontend\node_modules`) и запустите `start.bat` снова |
| Изменил `requirements.txt`, но ничего не поменялось | Удалите папку `.venv` и запустите `start.bat` |
| Сайт открылся пустым | Подождите несколько секунд и нажмите F5 |
| Шрифты выглядят иначе | Шрифты Onest и Literata подгружаются из интернета. Без интернета включаются системные: всё работает, меняется только вид |

## Следующие этапы

**AI-ответы.**
- Backend: новый роутер `backend/app/routers/ai.py` и сервис `services/ai.py`. Ключ положите в `.env` (`AI_API_KEY`, место уже подготовлено в `.env.example`).
- Сайт: на странице `Assistant.tsx` есть отключённая кнопка «Черновик от AI». Её нужно подключить к новому адресу.
- Статьи базы знаний уже подбираются через `/api/knowledge/suggest`. Их можно передавать в запрос к модели как источник фактов, чтобы ответы опирались на вашу базу.

**MCP.** Подключается отдельным сервисом рядом с backend. Данные обращений и базы знаний доступны ему через `services/tickets.py` и `services/knowledge.py`.

**Оплата.** Сейчас `POST /api/plans/select` просто меняет тариф. Платёжный сценарий добавляется в `services/plans.py` и на страницу `Plans.tsx`: в функции `select` перед сменой тарифа нужно добавить шаг оплаты.
